# Java Event-Driven Trading & Risk Platform

A simulated financial trading platform built with Java, Spring Boot, PostgreSQL, Redis, Kafka, and Docker Compose.

## Project Goal

This project aims to demonstrate backend engineering ability, financial trading system understanding, event-driven architecture, portfolio accounting, risk controls, and AI-assisted anomaly detection.

## Current Status

Week 1: Project infrastructure setup.

## Tech Stack

* Java 21
* Spring Boot 3.x
* Maven
* PostgreSQL 16
* Redis 7
* Apache Kafka
* Flyway
* Docker Compose

## How to Run

```bash
docker compose up -d
mvn spring-boot:run
```

## Current Features

* Project skeleton
* Docker Compose infrastructure
